# Food E-Commerce Admin Panel

A modern and responsive **Admin Panel** for the Food E-Commerce platform built with **Next.js** and **TypeScript**.

🚧 This project is currently under active development.

## Features

* Admin authentication (Login)
* Dashboard
* Products management
* Categories management
* Users management
* Orders management
* Transactions management
* Discount management
* Responsive admin interface

## Tech Stack

* Next.js
* React
* TypeScript

## Backend

This project consumes a separate REST API.

The backend and database are **not included** in this repository.

## Installation

```bash
git clone https://github.com/mahzadkhosraviani/food-ecommerce-admin.git

cd next-admin

npm install

npm run dev
```
